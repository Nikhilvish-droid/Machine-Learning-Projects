# Machine Learning Projects

A collection of machine learning projects I'm building while learning ML — covering data cleaning
and EDA, model training and evaluation, and turning trained models into small usable scripts.

## Projects

| # | Project | Description |
|---|---------|-------------|
| 1 | [Energy Consumption Predictor](./1-energy_consumption_predictor) | Predicts a household's daily electricity consumption (kWh) from household/HVAC attributes and live weather data, using a scikit-learn Linear Regression pipeline. |
| 2 | [Customer Loan Approval Prediction](./2-customer_loan_approval_prediction) | Predicts whether a loan application will be Approved or Rejected from an applicant's financials and CIBIL score, using a scikit-learn Logistic Regression pipeline. |
| 3 | [Network Intrusion Detection](./3-ntetwork_intrusion_detection) | Classifies network flows as BENIGN or as a specific attack type from CICIDS2017-style flow statistics, using a Decision Tree tuned with GridSearchCV. |

More projects will be added here as I keep learning.

## About

Each project lives in its own folder with its own `readme.md`, notebooks for exploration, and a
`src/` folder with the cleaned-up scripts. The goal is to practice the full workflow — from raw
data to a saved model to a working prediction script — one project at a time.
